# Mã hóa cổ điển và hiện đại

Thư mục tổng hợp ba bài thực hành của học phần An toàn và Bảo mật Hệ thống Thông tin.

- **TH1_LAB10 – Mã hóa cổ điển:** mã nguồn Java Swing, các thuật toán mã hóa cổ điển, kịch bản SQL Server, hình ảnh minh chứng và báo cáo thực hành.
- **TH2_LAB11 – Mã hóa đối xứng hiện đại:** DES, TripleDES, AES-GCM, RC4, Twofish, AES-CTR và bài nâng cao AES-CBC với Python; kèm mã nguồn, SQL Server, hình ảnh và báo cáo.
- **[TH3_LAB3 – Mã hóa khóa công khai](TH3_LAB3/):** RSA-2048/3072, RSA-OAEP, ECC, hệ mã lai RSA + AES-GCM và chữ ký số ECDSA; kèm mã nguồn Java Maven, giao diện Swing, kiểm thử JUnit, kịch bản SQL Server và báo cáo thực hành có hình ảnh minh chứng.

Mỗi thư mục có README riêng hướng dẫn nội dung và cách chạy. Đối với SQL Server, thiết lập cấu hình theo môi trường máy thực hành; không đưa thông tin đăng nhập thật lên GitHub.
